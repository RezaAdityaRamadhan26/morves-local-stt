# Panduan Rekaman Suara — Morves Local STT

Panduan ini untuk peserta yang membantu merekam suara untuk proyek STT
(speech-to-text) Morves Finance. Tidak perlu keahlian teknis apa pun.

## 1. ID Speaker Anda

Anda akan diberi ID anonim seperti `spk_002`.
**Pakai ID ini sebagai nama folder rekaman Anda.**
Nama asli, email, atau nomor telepon TIDAK boleh ada di file atau folder.

## 2. Daftar Kalimat

- Semua kalimat ada di `datasets/recording-pack/pilot-prompts.csv`
  (kalimat wajib bersama: `anchor-prompts.csv`).
- Setiap kalimat punya kode, misalnya `pp_049`. Perhatikan kodenya.

## 3. Satu Kalimat = Satu File

Rekam **setiap kalimat di file terpisah**. Jangan menggabungkan banyak
kalimat dalam satu rekaman.

## 4. Bicaralah dengan Natural

- Ucapkan kalimat seperti Anda bicara sehari-hari di kantor.
- Boleh sedikit santai ("Tampilin" vs "Tampilkan" tidak masalah).
- Kecepatan normal saja; boleh juga beberapa klip agak cepat/lambat.

## 5. JANGAN Mengeja atau Membaca Kaku

- Jangan mengucapkan huruf satu-satu ("M-E-D-I-T-A" ❌).
- Ucapkan angka seperti biasa: "dua ratus lima puluh juta" atau "dua ratus lima puluh juta rupiah".
- Jangan menambahkan kata yang tidak ada di kalimat.

## 6. Kalau Salah, Ulangi Saja

Rekam ulang kalimat yang salah ke file baru. Tidak perlu menghapus
rekaman lama — tim yang akan memilih take terbaik.

## 7. Jangan Ada Informasi Pribadi

- Jangan menyebut nama asli, nomor rekening asli, atau data pelanggan.
- Semua kalimat sudah aman dibaca (khusus dibuat untuk latihan).

## 8. Format & Alat

- Boleh pakai HP atau laptop; headset juga boleh (variasi itu bagus).
- Format yang diterima: OGG, M4A, MP3, WAV, FLAC. **Tidak perlu konversi.**
- Tempat yang cukup tenang saja; hindari speaker keras/kipas berdekatan.

## 9. Cara Mengirim

Taruh semua file dalam satu folder bernama ID Anda (contoh: `spk_002/`),
lalu kirim via kanal yang ditentukan tim (mis. Telegram ke tim data).
File boleh dinamai apa pun — sistem akan memetakan otomatis.

## 10. Privasi

- Rekaman hanya dipakai untuk melatih/menguji STT internal Morves.
- Rekaman TIDAK akan dibagikan ke luar dan tidak dimasukkan ke repositori kode.
- Minta tim hapus data Anda kapan pun — akan dihapus tanpa pertanyaan.

Terima kasih! 🎙️
